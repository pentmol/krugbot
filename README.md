# KrugBot

Telegram bot: пользователь отправляет кружок, после чего может смотреть кружки других пользователей.

## Запуск

1) Python 3.9+
2) Установка зависимостей:

```bash
python3 -m pip install -r requirements.txt
```

3) Запуск:

```bash
cp .env.example .env
# впиши токен в .env
python3 bot.py
```

По умолчанию база SQLite создается в `krugbot.sqlite3`. Можно переопределить через `DB_PATH`.

## Команды

- `/search` - искать кружки (смотреть)
- `/profile` - мой профиль
- `/my_video` - мой кружок (и перезапись)
 - `/start` - создание профиля

## Кнопки

Бот показывает клавиатуру с кнопками: `Искать`, `Мой профиль`, `Мой кружок`.
